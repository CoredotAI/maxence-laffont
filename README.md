# Maxence Laffont — CV & Cover Letter

Personal portfolio website displaying my CV and cover letter for the SIMS + DDMI (IÉSEG × EFREI) application.

## Features

- **Document switcher** — fixed right-side UI to toggle between CV and Cover Letter
- **3D hover effects** — interactive tilt on cards
- **Scroll animations** — fade-in on scroll with staggered delays
- **Parallax watermark** — subtle mouse-tracking background text
- **Responsive** — switcher adapts to mobile (bottom bar)
- **Print-ready** — clean output when printed

## Stack

Single-file HTML — no build step, no dependencies.

- HTML / CSS / vanilla JS
- Google Fonts: Syne, DM Mono, Instrument Serif

## Hosting

Hosted via **GitHub Pages** from the `main` branch.

### Deploy

1. Push to GitHub
2. Go to **Settings → Pages**
3. Set source to `main` branch, root `/`
4. Site will be live at `https://<username>.github.io/<repo-name>/`

## Files

| File | Description |
|------|-------------|
| `index.html` | Main website — CV + Cover Letter with switcher |
| `cv-maxence-laffont Efrei.html` | Standalone CV |
| `lettre-motivation-efrei-v8 (5).html` | Standalone Cover Letter |
